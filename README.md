# Curso de Front-End — Alura

Projeto prático desenvolvido durante a formação de Front-End da Alura, focado nos fundamentos de estruturação semântica e estilização para a web.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de elementos.
* **CSS3:** Estilização, layout e responsividade.

---

## 🎯 Funcionalidades & Conteúdo

* Estrutura base de cabeçalho (`<header>`) e seções de conteúdo.
* Organização de boas práticas de tags HTML.
* Estilização externa modularizada via arquivo `style.css`.
